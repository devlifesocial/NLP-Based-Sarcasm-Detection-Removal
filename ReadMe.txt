Folder structure:
1. Code
	1.1 Readme
	1.2 Paper_Implementatio
	1.3 Sarcasm_Removal_code
	1.3 Novelty_code
	1.4 Datasets 
	1.5 Output

Start by navigating to the Paper Implementation folder. Inside, you’ll find two Jupyter Notebook files: one for the IAC dataset and another for the Onion dataset. These files contain the complete implementation of the research paper.

Next, move to the Novelty folder, where you’ll find the FNN.ipynb file (Feedforward Neural Network implementation). To run this file, load the IAC_dataset.csv and Onion_data.csv from the Dataset folder. If necessary, update the folder paths in the code. Running this notebook will produce the required outputs, including an accuracy of 89.12%, a training loss graph over epochs, and a confusion matrix.

Then, proceed to the Sarcasm_Removal section. This folder contains the sarcasm removal code, which leverages four pretrained models: T5-small, T5-base, BART, and DialoGPT. Additionally, there is an Accuracy Calculator file used to compute the accuracy of the four models on nonsarcastic text converted using the IAC dataset.

In the Dataset folder, you’ll find all the input datasets required for this project.

Finally, the Output folder contains the predictions generated by the various models.
